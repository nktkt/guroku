LEGEND -- hooks (cross-ref: docs/internals/lifecycle.md)
--------------------------------------------------------------------------------
  ROOT hooks    -- run once for the project's own package.json:
    preinstall  -- before resolve/fetch/link
    install     -- after linker finishes
    postinstall -- after `install` hook
    prepare     -- final root stage (also runs on `pack`/`publish`)

  PER-PKG hooks -- run per installed dependency, in dependency order:
    preinstall  -- before the package's own install script
    install     -- the package's main install script
    postinstall -- after the package's install script
                   (all per-pkg hooks: best-effort, warn-on-fail)

  Flags:
    --ignore-scripts    -- skips ALL ROOT and PER-PKG hooks
    --frozen-lockfile   -- skips the lockfile-write stage only

  Symbols:
    +----+   stage box
    <-->     parallel / streaming work inside a stage
    -->      sequential edge between stages

  Reference: docs/internals/lifecycle.md (sections: "Root hooks",
             "Per-package hooks", "Flags & skipping").

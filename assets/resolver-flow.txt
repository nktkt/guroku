guroku v0.2 -- install pipeline
================================================================

         +-------------------------+
         |  read package.json      |
         +-------------------------+
                     |
                     v
         +-------------------------------------+
         |  parse roots into (name, range)     |
         |  pairs   -->   work queue           |
         +-------------------------------------+
                     |
                     v
+---------------------------------------------------------------+
|                          resolver                             |
|                                                               |
|     +-----------------------------+                           |
|     |  dequeue (name, range)      |<---------------+          |
|     +-----------------------------+                |          |
|                  |                                 |          |
|                  v                                 |          |
|        < name already chosen? >                    |          |
|           |                |                       |          |
|         yes|              no|                      |          |
|            v                v                      |          |
|   +-----------------+  +------------------+        |          |
|   | check range     |  | fetch metadata   |        |          |
|   | vs prior choice |  | (registry GET)   |        |          |
|   +-----------------+  +------------------+        |          |
|            |                   |                   |          |
|            |                   v                   |          |
|            |       +-----------------------------+ |          |
|            |       | max_satisfying(vers, range) | |          |
|            |       +-----------------------------+ |          |
|            |                   |                   |          |
|            |                   v                   |          |
|            |       +-----------------------------+ |          |
|            |       | record choice in resolution | |          |
|            |       +-----------------------------+ |          |
|            |                   |                   |          |
|            |                   v                   |          |
|            |       +-----------------------------+ |          |
|            |       | enqueue dependencies        |-+          |
|            |       +-----------------------------+            |
|            |                                                  |
|            +---->  [ continue with next item ]                |
|                                                               |
|                  queue empty?  --yes-->  exit resolver        |
+---------------------------------------------------------------+
                     |
                     v
         +-------------------------+
         |  write guroku.lock      |
         +-------------------------+
                     |
                     v
+---------------------------------------------------------------+
|              for each chosen package (parallel)               |
|                                                               |
|              < cache hit in ~/.guroku/store ? >               |
|                  |                       |                    |
|                yes|                    no|                    |
|                   v                       v                   |
|        +------------------+   +----------------------------+  |
|        | skip download    |   | fetch tarball from         |  |
|        |                  |   | registry                   |  |
|        +------------------+   +----------------------------+  |
|                   |                       |                   |
|                   |                       v                   |
|                   |           +----------------------------+  |
|                   |           | verify SHA-512 of tarball  |  |
|                   |           +----------------------------+  |
|                   |                       |                   |
|                   |                       v                   |
|                   |           +----------------------------+  |
|                   |           | extract to                 |  |
|                   |           | ~/.guroku/store/<pkg>@<v>  |  |
|                   |           +----------------------------+  |
|                   |                       |                   |
|                   +-----------+-----------+                   |
|                               |                               |
+-------------------------------|-------------------------------+
                                v
         +-------------------------------------+
         |  flat copy into                     |
         |  ./node_modules/<name>              |
         +-------------------------------------+
                     |
                     v
                 [ done ]


Legend (module : file)
----------------------
  manifest : src/manifest.rs       (read package.json)
  resolver : src/resolver.rs       (queue, max_satisfying, choices)
  registry : src/registry.rs       (metadata + tarball fetch)
  lockfile : src/lockfile.rs       (write guroku.lock)
  store    : src/cache.rs          (~/.guroku/store, SHA-512)
  linker   : src/linker.rs         (flat copy to node_modules)
